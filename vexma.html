Project 4 : UI/UX · Internal Tool
UI/UX Design · Vexma Cloud (internal manufacturing workflow software)

VEXMA CLOUD

Job Card Dashboard

Vexma Cloud is a subdivision software of Vexma Technologies used to manage the manufacturing workflow. It includes a Machine Working Dashboard that tracks how much work each machine has completed via “Job Cards” (i.e., orders).

Task: Redesign the Job Card UI component so that at a glance, a user can see — for a particular technology — how many machines are running, and how many job cards are pending or assigned to each.

Outcome: The new card design lets users instantly understand, per technology, how many job cards exist and their distribution across machines — improving clarity and reducing time spent scanning the dashboard.
